通过构建系统去持续认知升级。

## 认知升级闭环

```
认知 → 目标 → 系统 → 更高认知 → 更高目标 → ...
```

认知决定目标背后的 Why，只有通过构建系统才能确定性地达成目标。

## 知识分类

| 类型 | 含义 |
|:---|:---|
| **Know-What** | 事实知识 |
| **Know-Why** | 原理知识 |
| **Know-How** | 技能知识 |
| **Know-Who** | 人际知识 |

## 冰山模型 (Daniel Kim, 1999)

| 层次 | 思考类型 | 可复制性 |
|:---|:---|:---|
| 事件 | 战术 (Tactics) | 最容易复制 |
| 规律 | 战术 | 容易复制 |
| 结构 | 战略 (Strategy) | 难以复制 |
| 思维方式 | 战略 | 难以复制 |
| 价值观 | 预见 (Vision) | 几乎不可复制 |
